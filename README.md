# «Распознаватель» — портативная офлайн-программа для Windows

**QR-коды · Штрих-коды · Текст с картинок · Текст с экрана · Перевод 60+ языков · История распознаваний**

---

## ✅ СБОРКА (v2.5.0 — исходники, требуется пересобрать)

В этом архиве — **исходный код** (папки `dist/` с готовым exe здесь нет).
Сборка под Windows: двойной клик по **`build.bat`** (нужны Python 3.11 x64
и интернет только на время сборки). Результат — **портативная папка**:

```
dist\Raspoznavatel\
├── Raspoznavatel.exe   ← запуск отсюда
└── App\                ← все ресурсы и библиотеки
```

Папку можно носить целиком (флешка), установка и права администратора не
нужны. Запуск **быстрый**: в отличие от прежней single-file сборки (351 МБ),
ничего не распаковывается при каждом старте.

Диагностика после сборки (рекомендуется):

| Режим | Как запустить | Результат |
|---|---|---|
| Компоненты | `set RASPOZ_SELFTEST=1` и запуск exe | `Raspoznavatel_data\selftest_report.txt` (Tesseract, OCR, QR, перевод, tkinter, mss, keyboard) |
| Интерфейс и мост | `set RASPOZ_E2E=1` и запуск exe | `Raspoznavatel_data\e2e_report.txt` — программа САМА кликает кнопки, проверяет журнал, горячие клавиши и закрывается |
| DevTools | `set RASPOZ_DEBUG=1` и запуск exe | окно с инструментами разработчика WebView2 |

* **Кнопка «История»** рядом со «Скриншот области»: все распознавания (текст и

  индекса Argos и дальше работают офлайн; пары без прямой модели идут

  текст) — раньше на части систем оно было белым с невидимыми надписями;
  клик левой кнопкой по иконке переключает окно (показать/скрыть).
* **Панель задач**: клик по кнопке приложения снова сворачивает окно
  (безрамочному окну возвращён стиль WS_MINIMIZEBOX).
* **Русский OCR с экрана**: турнир вариантов предобработки (увеличение,
  Оцу, инверсия для тёмных тем, адаптивный порог × psm 6/3) — тёмные темы,
  мелкий кегль и цветные фоны распознаются уверенно (95%+ на тестах).
* **Установщик с иконкой приложения**: директивы MUI_ICON перенесены до
  `!include "MUI2.nsh"` (раньше игнорировались NSIS) + явные Icon/UninstallIcon.

## 🔧 Версия 2.2 — исправлено (по жалобам пользователя)

1. **Все кнопки снова работают.** В `main.py` объект Api не передавался в
   `webview.create_window(js_api=api)` — мост `window.pywebview.api` в
   JavaScript был пуст, поэтому «Распознать с экрана», «Скриншот»,
   «Загрузить изображение» и кнопки окна (свернуть/развернуть/закрыть)
   не делали ничего.
2. **Ошибки больше не «немые».** Прежде сбой кнопки оставался внутри JS и
   не доходил до Python — в файле журнала ничего не появлялось. Теперь:
   каждый вызов API и каждая ошибка пишутся в `Raspoznavatel_data\app.log`
   (и видны в панели «Настройки → Журнал»); JS-ошибки доставляются через
   `js_error`; журнал ведёт ротацию (~5 МБ).
3. **Быстрый запуск.** Устранено зависание: строки журнала, отправленные в
   интерфейс ДО загрузки страницы, вызывали `evaluate_js`, который
   блокировался на 20 секунд на каждой строке и уходил в рекурсию — окно не
   появлялось вовсе. Теперь журнал буферизуется и доставляется пакетом после
   события `loaded`. Дополнительно: постоянный профиль WebView2
   (`private_mode=False`), ленивый импорт PIL/mss, сборка onedir вместо
   onefile (без распаковки 351 МБ на каждом запуске).
4. **Крестик закрывает программу** (раньше процесс мог оставаться висеть:
   pywebview-мост блокировался после разрушения окна — закрытие выполняется
   корректно на всех бэкендах, процесс гарантированно завершается).
5. **Горячие клавиши настраиваются**: Настройки → «Записать» → нажмите любую
   комбинацию **от 2 клавиш** (например Ctrl+F9 или Alt+Q). Запись идёт по
   физическому коду клавиши — русская раскладка не мешает (Ctrl+Shift+S
   запишется правильно, а не как «ctrl+shift+ы»). Системные комбинации
   (Alt+F4, Alt+Tab, Win+L…) отклоняются с понятной ошибкой; совпадающие
   комбинации для распознавания и скриншота — тоже.
6. **Автозагрузка при включении ПК**: Настройки → «Запускать вместе с
   Windows» — программа стартует **свёрнутой в трей** (ярлык в папке
   «Автозагрузка», без реестра и админ-прав), горячие клавиши работают
   сразу; при захвате экрана окно не выскакивает, если было спрятано.
7. Прочее: «Сохранить как…» открывает диалог СОХРАНЕНИЯ файла (SAVE_DIALOG=30,
   раньше — выбор папки); «Загрузить изображение» не падает (исправлено имя
   параметра `dialog_type`); поиск HWND окна проверяет PID процесса.

Всё проверено автоматикой: 32/32 юнит-теста, 29/29 UI-тестов (headless
Chromium), 14/14 E2E-самопроверок реального приложения (pywebview).

## Как получить готовый .exe

### Способ 1 — облачная сборка GitHub Actions (НИЧЕГО не устанавливая на свой ПК)

Файл workflow есть в проекте: `.github/workflows/build-windows.yml`.
В репозитории на GitHub его пока НЕТ: загрузка файлов в `.github/workflows/`
требует токен с правами `workflow` (у токена агента только `repo` — иначе
GitHub отклоняет пуш). Включается ОДИН раз вручную: откройте репозиторий на
github.com → *Add file → Create new file* → имя
`.github/workflows/build-windows.yml` → вставьте содержимое файла из проекта →
*Commit changes*. (Либо выдайте агенту токен со scope `repo + workflow` — он
зальёт файл сам.)

Дальше:

1. Вкладка **Actions** → *Build Windows EXE* → **Run workflow**.
2. Через ~15–25 минут на странице запуска скачайте артефакт
   **Raspoznavatel-exe** — внутри готовая портативная папка `Raspoznavatel\`
   (`Raspoznavatel.exe` + `App\`). Модели перевода workflow скачает сам.

### Способ 2 — сборка на своём Windows-ПК (один двойной клик)

Требования: Windows 10/11 x64, Python 3.11 x64 с галочкой *«Add python.exe to PATH»*.

```bat
cd raspoznavatel
build.bat
```

`build.bat` сделает всё сам: окружение → зависимости → ресурсы
(включая **автоматическое скачивание и тихую установку Tesseract-OCR**,
понадобится один раз нажать «Да» в окне UAC) → сборка
`dist\Raspoznavatel.exe`.

> Все сообщения build.bat продублированы транслитом намеренно: файл в чистой
> ASCII-кодировке и гарантированно не выдаёт «иероглизы» ни на одной версии
> Windows. Сообщения самой программы — на русском.

### Способ 3 — вручную

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python tools\download_resources.py
pyinstaller build.spec --noconfirm --clean
:: итог: dist\Raspoznavatel.exe
```

### Способ 4 — сборка в Linux через Wine (проверено, так и был собран готовый exe)

```bash
# 1. Wine 8+, затем инициализация префикса
export WINEPREFIX=~/.wine WINEDEBUG=-all
wineboot -u

# 2. Windows-Python: NuGet-пакет "python" 3.11.9 + tkinter из MSI официального
#    установщика (распаковывается 7-Zip'ом из python-3.11.9-amd64.exe)
#    -> собрать в ~/.wine/drive_c/winpy (python.exe, Lib, DLLs, tcl/)

# 3. Зависимости и сборка
wine C:\\winpy\\python.exe -m pip install -r requirements.txt
wine C:\\winpy\\python.exe -m PyInstaller build.spec --noconfirm --clean
```

### Самодиагностика exe

У консольной сборки (или при `console=True` в spec) можно запустить полную
проверку всех компонентов прямо внутри замороженного приложения:

```bat
set RASPOZ_SELFTEST=1
Raspoznavatel.exe
```

Отчёт проверяет: встроенный Tesseract, OCR, движки QR, офлайн-перевод,
tkinter и mss. В финальной (оконной) сборке переменная просто игнорируется
видимым образом — все проверки те же выполняются приложением в рантайме.

## Запуск готовой программы

1. Скопируйте `Raspoznavatel.exe` куда угодно (флешка, рабочий стол).
2. Двойной клик — без установки и без прав администратора.
3. Настройки и распакованная модель перевода хранятся в папке
   `Raspoznavatel_data` рядом с `.exe` (если путь содержит кириллицу или
   запись запрещена — в `C:\ProgramData\Raspoznavatel`). **В реестр Windows
   ничего не пишется.**

### Важные примечания

* **Первый запуск занимает ~15–40 секунд**: PyInstaller распаковывает
  встроенные ресурсы (включая модель перевода 187 МБ) во временную папку.
* **Первый перевод** дополнительно распаковывает модель в папку данных
  (один раз, ~10–20 секунд); программа прогревает её в фоне сразу после
  запуска. Следующие переводы — за ~1 секунду.
* **WebView2**: системный компонент Windows 10/11, обычно уже установлен.
  Если его нет, Windows один раз предложит его установить (компонент
  Microsoft; сама программа остаётся полностью офлайн).
* Антивирус может ложно срабатывать на любой .exe, упакованный PyInstaller —
  добавьте файл в исключения или соберите .exe сами из этого исходного кода.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| **Ctrl+Shift+S** | Выделить область экрана → «умное» распознавание (сначала QR, затем текст) |
| **Ctrl+Shift+P** | Скриншот выделенной области (автосохранение в папку) |
| **Esc** (в режиме выделения) | Отмена |

Обе комбинации **настраиваются**: Настройки → «Горячие клавиши» → «Записать» →
нажмите любую комбинацию от 2 клавиш (например Ctrl+F9 или Alt+Q). Запись идёт
по физическому коду клавиши — русская раскладка не мешает. Системные
комбинации (Alt+F4, Win+L и т.п.) отклоняются.

## Что именно встроено внутрь .exe

| Ресурс | Размер | Назначение |
|---|---|---|
| `resources/tesseract/` | ~68 МБ | движок Tesseract-OCR 5.5.3 (tesseract.exe + DLL из официальных пакетов MSYS2, согласованный набор) |
| `resources/tessdata/` (15 языков) | ~50 МБ | рус, англ, укр, бел, каз, нем, франц, исп, итал, порт, пол, тур, нидерл, чеш, кит (tessdata_fast); другие языки — положить `<код>.traineddata` в эту папку |
| `resources/argos/translate-en_ru-1_9.argosmodel` | 195,7 МБ | нейромодель перевода EN→RU |
| `resources/argos/translate-ru_en-1_9.argosmodel` | 149 МБ | нейромодель перевода RU→EN |
| `ui/` (HTML/CSS/JS + шрифты + иконка) | ~0,3 МБ | интерфейс, шрифт Inter |
| Python + все библиотеки | ~130 МБ | среда выполнения |

Итог сборки — портативная папка `dist\Raspoznavatel\` (~550-620 МБ): `Raspoznavatel.exe` + `App\` со всем содержимым. Запуск быстрый — ничего не распаковывается.
