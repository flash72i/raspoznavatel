⚡ Распознавание запускается автоматически (сначала QR, затем текст)
Языки текста определяются автоматически — даже смешанные Русский + английский + китайский на одной картинке распознаются вместе: программа определяет письменности параллельными пробами и выполняет один проход комбинированным набором языков. Также доступны украинский, немецкий, французский, испанский, итальянский, португальский, польский, турецкий, нидерландский, чешский, белорусский, казахский — и любой другой, чей файл .traineddata положен в App\resources\tessdata.

Языки перевода

В комплекте — офлайн-пакеты EN↔RU. Остальные направления (60+ языков) скачиваются один раз из официального индекса Argos прямо из окна перевода: выберите язык с пометкой «скачать» — дальше он работает офлайн. Пары без прямой модели переводятся транзитом через английский.
