## Что исправлено в текущей версии
1. **Перевод не просит скачать пакет.** В `translator._CYR_HINTS` признаком
   белорусского языка числилась буква **«Ы» — обычная русская буква**. Любой
   русский текст с заглавной «Ы» («ВЫШЛА», «ТЫ», «СЫН») определялся как `be`,
   а модели `be->ru`/`be->en` в программе нет → ошибка «Скачайте языковой пакет».
   Теперь:
   * «Ы» убрана из подсказок (остались только буквы, которых нет в русском:
     і, ї, є, ґ, ў, ә, ғ, қ…);
   * для ДЛИННОГО текста одной отличительной буквы мало (нужно ≥2, либо ≥2 %
     букв) — случайная буква/имя не меняют язык всего текста; для короткого
     (≤60 кириллических букв) достаточно одной;
   * язык выбирается по количеству попаданий, а не по порядку в списке;
   * если определённый язык — «сосед» языка перевода и модели нет (be/uk при
     цели ru), текст возвращается как есть с понятной подписью, БЕЗ просьбы
     что-то скачать; при цели en такой текст переводится как ru.
2. **Номер версии больше нигде не «зашит».** Версия живёт только в
   `config.py:APP_VERSION` и `installer.nsi` (6-7 полей). Из README, из
   интерфейса (`ui/app.js`, `ui/index.html`, `styles.css`) и из комментариев кода
   убраны 67+ упоминаний «v2.x» — именно их владелец видел на сайте. В журнале
   программы в журнале больше нет строки с номером версии интерфейса;
   версию интерфейс берёт из `get_info()` (то есть из `config.py`).
   Тест №23 следит, чтобы в README не появилось номера версии.
3. Тесты: **180/180** (Linux), дымовой тест трея в Wine **20/20**, selftest
   собранного exe **10/10**. Уроки **L50** (версия в двух местах) и **L51**
   (подсказки языков: «Ы» — русская буква) в INSTRUCTIONS.md.

## Что было исправлено раньше (напоминание для следующей сессии)
* **Корень жалобы «иконка видна, но не нажимается»:** `_setup_prototypes()`
  падал на первой же привязке (`FillRect` искали в gdi32 вместо user32) → поток
  трея умирал сразу → значок создавал watchdog в своём потоке, без насоса
  сообщений; повторный запуск exe постил `WM_RASPOZ_SHOW` в мёртвую очередь и
  молча завершался. Теперь: прототипы поштучно в try/except; окно и значок
  создаёт только поток с насосом; здоровье = пульс `WM_TIMER`; колбэки кликов —
  в отдельном потоке; показ окна чистым Win32 (без блокирующего `Invoke` в
  GUI-поток pywebview); левый клик всегда показывает окно; single-instance ждёт
  подтверждения и при молчании запускается сам; страховка возвращает окно, если
  трей не отвечает; класс окна — свой на каждое поколение потока.
* **Регрессия прошлой сборки:** в `api._fix_window_styles` не хватало
  `from ctypes import wintypes` → NameError тонул в WARN, клик по кнопке на
  панели задач не сворачивал окно. Добавлена статическая проверка имён
  `tools/pyflakes_check.py` (запускается этапом `doctor` и тестом №25).
